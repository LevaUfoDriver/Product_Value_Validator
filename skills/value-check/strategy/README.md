# Strategy folder

Context for the "link to strategy" criterion goes here:

- `strategy-digest.md` — a condensed digest of the strategy (1–2 pages: goals, initiatives, metrics, job families one line each). Created by the skill on the first load of the full document, or by the team by hand.
- `goals-<period>.md` (e.g. `goals-2026-Q4.md`) — goals for the current quarter/month, if they aren't in the strategy. Numbers not required. This is what tickets are tied to here and now — update every period.
- Any exports from the internal goals site / Confluence (markdown, txt) — the skill finds them by names like `strategy*`, `okr*`, `goals*`, `job-families*`.

The full strategy document doesn't have to be placed here — it's large, and the skill will make a digest anyway. Update the digest when the quarter or goals change.
