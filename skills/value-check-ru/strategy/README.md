# Папка стратегии

Сюда кладётся контекст для критерия «связь со стратегией»:

- `strategy-digest.md` - сжатая выжимка стратегии (1–2 страницы: цели, инициативы, метрики, job family по одной строке). Создаёт скилл при первой загрузке полного документа или команда вручную.
- `goals-<период>.md` (например `goals-2026-Q4.md`) - цели текущего квартала/месяца, если они не в стратегии. Можно без цифр. Это то, к чему привязаны задачи здесь и сейчас - обновлять каждый период.
- Любые экспорты с внутреннего сайта целей / Confluence (markdown, txt) - скилл их найдёт по именам вида `strategy*`, `okr*`, `goals*`, `job-families*`.

Полный документ стратегии сюда класть не обязательно - он большой, и скилл всё равно сделает выжимку. Обновляйте выжимку при смене квартала или целей.
