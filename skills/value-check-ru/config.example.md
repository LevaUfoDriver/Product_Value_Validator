## Поведение

- **Помощь в формулировках:** `вкл` - после вопросов скилл предлагает перевести ответ автора в формулировку для задачи. `выкл` - только вопросы и черновик с пропусками. В разговоре отключается фразой «без помощи».

- **Язык отчётов:** `авто` (язык собеседника) или укажите: `русский` / `english`
- **Задач за раз в групповом режиме:** 10 по умолчанию, не больше 20
- **Комментарии в Jira:** только после явного подтверждения (фиксировано)
